# Cinematic Bars (Fabric, Minecraft 1.21.4, client-only)

F1 скрывает интерфейс, и сверху и снизу плавно появляются чёрные киношные полосы (кадр 2.39:1).
Открыл меню или инвентарь, и полосы убираются.

## Сборка
Нужна Java 21.
    gradle build        (или ./gradlew build, если есть wrapper)
Готовый мод: build/libs/cinematic-bars-1.0.0.jar (НЕ файл с -sources)

## Без установки чего-либо
Залей папку на GitHub, вкладка Actions → build → внизу в Artifacts скачай cinematic-bars-jar.
